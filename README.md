# Blood Donor Management System – C Day 109

## Description
A menu-driven C application to maintain blood donor records using structures and file handling.

## Features
- Add new donors
- View all donor records
- Search donors by blood group
- Display total donor count
- Save records permanently in a text file

## Technologies
- C Programming
- Structures
- File Handling

## Files
- `donor.c`
- `donors.txt`

## How to Compile
```bash
gcc donor.c -o donor
```

## How to Run
```bash
./donor
```

## Concepts Used
Structures, Arrays, File Handling, Searching, String Comparison and Menu-driven Programming.

**Note:** This is an educational record-management project, not a medical donor eligibility system.
